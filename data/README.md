# Data

`policy_corpus.md`는 POL 규정·플랫폼 공식 요약, `company-a-access-matrix.md`는 가상 회사의 접근 권한표입니다.
원본 2번 프로젝트의 초안·출처 표기를 유지했습니다. 정책 간 해석은 [정책 결정 기록](../docs/policy-decisions.md)에 있습니다.
인사·예산·현재 권한은 문서에서 추측하지 않고 모의 PostgreSQL에서 정확 조회합니다.

생성 데이터는 `data/checkpoints/`, `data/indexes/`, `data/runtime/` 등 Git 제외 경로에 둡니다.
원본 문서의 변경은 검색 근거 해시에 반영되므로 정책 변경 시 관련 시나리오를 확인해야 합니다.
