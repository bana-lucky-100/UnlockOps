# 평가 조건과 재현 방법

## 팀 비교 실험 기록

아래는 제공된 `03_검증결과서_양식_UnlockOps.pptx` 2~4장과 `UnlockOps 발표자료.html`의 결과 장에 기록된 팀 실험을 요약한 것이다. README 수정 과정에서 모델 평가를 다시 실행한 결과는 아니다.

| 항목 | 조건 |
|---|---|
| 실행일 | 2026-10-23 |
| 입력 | `natural-v1` 자연어 요청 20문항, 정책 revision 4 |
| 모델 | `gpt-4o-mini`, temperature 0 |
| 비교 | v1 자유 권한명 생성 → v2 실제 권한 후보 선택 |
| 실행 횟수 | 개선 전·후 각 1회 |
| 판정 일치 | 기대 상태·사유 코드와 같은 결과인지 비교 |

| 지표 | 개선 전 | 개선 후 |
|---|---:|---:|
| 판정 일치 | 11/20 (55%) | 17/20 (85%) |
| 요청과 다른 권한이 승인 대기로 진행 | 1건 | 0건 |
| 정상 신청 7건의 불필요한 수동 검토 | 7건 | 0건 |
| 분석 시간 중앙값 | 2.1초 | 6.2초 |

판정 일치와 잘못된 승인 진행 수는 검증결과서 3~4장 및 발표자료에, 수동 검토 건수와 분석 시간 중앙값은 발표자료에 기록되어 있다. 검증결과서 4장은 별도 회귀 평가 33/33 통과도 기록하지만, 이는 자연어 20문항의 충족률과 다른 검사다.

**해석 범위:** 소규모 합성 데이터의 단회 비교다. 일반적인 모델 정확도나 실제 SaaS 운영 성능으로 확장해 해석하지 않는다. 비교 실험의 전체 원시 CSV·실행 보고서는 현재 저장소에 추적되어 있지 않아 커밋별 수치를 독립 재집계할 수 없다. 검색 적중률과 설명 품질도 별도 측정하지 않았다.

## 개선 내용과 남은 실패

LLM이 `Editor` 같은 자유 권한명을 생성하면 실제 권한 코드와 어긋날 수 있었다. 현재는 서버가 제공한 후보 ID 하나 또는 `null`을 구조화 출력으로 받고, 요청 자원·역할 범위와 다시 대조한다. 구현은 [권한 선택](../agent/unlockops/access/selection.py)에서 확인할 수 있다.

| 문항 | 관측된 실패 | 의미 |
|---|---|---|
| N-07 | Slack과 Notion을 함께 언급한 편집 요청을 수동 검토로 처리 | 잘못된 권한 승인 경로는 차단했으나 목적 플랫폼 해석은 미해결 |
| N-16·N-17 | 읽기 목적·관리자 권한 불필요 등의 표현을 수동 검토로 처리 | 부정 표현과 최소 권한 의도 해석 보완 필요 |

문항 원문·기대값은 [자연어 평가셋](../data/phase2/scenarios-natural-v1.json)을 따른다. 기존 [구조 검증 기록](verification.md)은 기록 날짜와 검사 범위가 다르므로 위 실험의 재실행 증거로 사용하지 않는다.

## 재현 방법

Docker를 사용할 수 있는 환경에서 프로젝트 루트에서 실행한다. 실행기는 매번 별도 프로젝트·DB를 만들고 사전조건, HTTP 결과, 예산·권한·영수증 부수효과를 검사한다.

```sh
# 규칙 기반 전체 회귀 평가: 기본 demo 모드
python3 scripts/evaluate_phase2.py --run --suite full

# 자연어 요청의 모델 평가: 루트 .env에 LLM_API_KEY·LLM_MODEL 설정 필요
python3 scripts/evaluate_phase2.py --run --suite natural --agent-mode llm
```

새 실행의 결과는 `test-results/phase2/<run_id>/report.json`과 `runtime.log`에 저장한다. 모델명·코드 버전·실행 모드와 판정 일치 수, 잘못된 승인 경로 수, 수동 검토 수, 분석 시간 p50/p95를 함께 기록한다. 기존 수치와 비교할 때는 같은 입력·기대값·모델 설정을 사용하고 각 측정 커밋과 원시 결과를 보존해야 한다.

- [평가 실행기](../scripts/evaluate_phase2.py)
- [지표 계산](../scripts/phase2/metrics.py)
- [현행 시나리오·사전조건 안내](../data/phase2/README.md)

실제 SaaS 연동, 브라우저 클릭, 검색·보고서 품질은 이 실행기의 자동 평가 범위와 구분한다.
