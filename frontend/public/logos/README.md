# 로그인 화면 SaaS 로고

로그인 화면 왼쪽 띠에 표시하는 관리 대상 SaaS 로고 자리입니다.
파일이 없으면 화면에 SaaS 이름(글자)이 대신 보이므로, 넣지 않아도 화면은 깨지지 않습니다.

## 넣는 방법
- 각 사 **공식 브랜드(프레스) 키트**에서 받은 SVG만 넣습니다. 직접 그리거나 모양·비율을 바꾸지 않습니다.
- 파일 이름은 아래 표의 이름 그대로(소문자). 확장자는 .svg를 먼저 찾고, 없으면 .png를 씁니다.
- PNG는 투명 배경 · 흰색 단색(높이 96px 정도)으로 넣습니다. 현재 PNG 10개는 받은 로고를 흰색 단색으로만 바꾼 것입니다(figma.png는 공식 흰색 심볼과 흰색 글자 로고를 가로로 나란히 붙였습니다). slack.png는 공식 로고 PDF에서 아래 'from Salesforce' 줄을 뺀 위 로고만 썼습니다.
- tableau.svg는 공식 키트가 아닌 로고 모음 사이트에서 받은 파일입니다. 공식 파일을 구하면 교체합니다.
- 화면에서 색을 바꾸지 않으므로 흰색(또는 어두운 배경용) 버전을 넣습니다.
- 가로형(심볼 + 이름) 로고 권장. 높이 24px로 맞춰 보입니다.

## 주의
- 이 저장소는 공개 저장소입니다. 각 사 브랜드 가이드의 사용 조건(변형 금지, 여백 등)을 확인하고 넣어 주세요.
- 로고는 "이 SaaS들의 권한을 관리한다"는 표시로만 씁니다. 제휴·보증처럼 보이는 문구는 붙이지 않습니다.
